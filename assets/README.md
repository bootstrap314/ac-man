# App icon

`AppIcon.png` is the transparent source artwork. `AppIcon.icns` contains the standard macOS sizes, including Retina representations. Rebuild it on macOS with `bash scripts/build-icon.sh`.

Artwork prompt (built-in image generation):

> Create a production-ready macOS application icon for an air conditioner controller named ac-man. A cute, friendly little wall-mounted air conditioner mascot, softly rounded white housing, simple dark eyes and a small happy smile, a few pale icy-blue vent fins, and one subtle blue breeze curl. Polished tactile 3D illustration, clean deliberate geometry, instantly recognizable at small sizes. Center it on a rounded-square deep teal to blue tile, with soft studio highlights and gentle depth. The tile occupies about 86% of the square canvas, leaving transparent padding outside its rounded corners. No text, no letters, no logos, no extra objects. Square high-resolution icon, crisp silhouette, warm approachable personality rather than a toy scene.
