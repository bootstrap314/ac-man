# ac-man v0.0.2

## Downloads

**Mac menu-bar app:** [Download the Apple Silicon DMG](https://github.com/bootstrap314/ac-man/releases/download/v0.0.2/ac-man-app-v0.0.2-macos-apple-silicon.dmg). Open it and drag ac-man into Applications. The app and installer are Developer ID signed and notarized. Requires macOS 13 or later; the graphical app is currently Apple Silicon only.

**Terminal CLI:** choose the tarball for your platform. These contain the command-line program, not the menu-bar app.

- [Apple Silicon Mac CLI](https://github.com/bootstrap314/ac-man/releases/download/v0.0.2/ac-man-v0.0.2-aarch64-apple-darwin.tar.gz)
- [Intel Mac CLI](https://github.com/bootstrap314/ac-man/releases/download/v0.0.2/ac-man-v0.0.2-x86_64-apple-darwin.tar.gz)
- [Linux x86_64 CLI](https://github.com/bootstrap314/ac-man/releases/download/v0.0.2/ac-man-v0.0.2-x86_64-unknown-linux-gnu.tar.gz)

`SHA256SUMS` contains archive checksums; `SOURCE.txt` identifies the source and build run.

## Mac menu-bar app

- Install using a signed and notarized DMG: open it and drag ac-man to Applications.
- New AC mascot application icon. The menu bar retains its monochrome symbol.
- Smaller control window that fits the available settings.
- Appearance follows macOS: blue-tinted blur in light mode and graphite blur in dark mode, with an opaque fallback when Reduce Transparency is enabled.
- Controls stay interactive while cloud requests run; newer changes are combined and sent in order.
- Rapid temperature clicks update the target immediately and send one cloud request after a half-second pause.
- Centered room name with a small rename pencil, room temperature, and round power button: green when on and red when off.
- Power button alternates red and green when communication fails, returning to its normal color after recovery.
- Quiet background updates without a refresh button, timestamp, or routine applying messages.
- Removed the disabled SmartHome cloud menu entry.
- Vertical and horizontal vent-position selectors appear on supported units. Positions 1–5 are presets, not degrees; swing remains available.

## Terminal CLI

- Added `vertical-angle` and `horizontal-angle` commands, plus matching `set` options.
- Vent changes are checked against reported capabilities and confirmed by reading the device back.

Release downloads distinguish the Mac application installer from the separate Mac and Linux command-line archives.
