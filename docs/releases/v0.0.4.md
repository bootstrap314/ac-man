# ac-man v0.0.4

## What’s new

- Added visual vent position tiles with distinct directional arrows and a segmented Swing selector.
- Added native control regression tests to macOS CI.

- Automatic fan, Boost, and Eco toggles are mutually exclusive: selecting one clears the other two in the same request.

- Fixed the fan slider thumb disappearing during dragging on the blurred control window.

- Fixed reserved fan-speed codes being displayed as percentages such as 101%. Unknown readings now show as unavailable, while the slider retains a valid manual setting.

- Added an Eco mode toggle below Boost for units that advertise standard Eco support. It uses the same responsive background updates and confirms changes against the unit’s reported state.
- Added CLI commands `ac-man <device> eco on|off` and `set --eco on|off`, plus Eco status reporting.
- Tightened the spacing between Automatic fan, Boost, and Eco mode for a more compact control window.
- Updated the light and dark README product images to match the new controls.

This supports standard Eco mode; the separate iECO feature is not included. Unsupported units show the toggle disabled.

## Downloads

**Menu-bar app:** Download `ac-man-app-v0.0.4-macos-apple-silicon.dmg`, open it, and drag ac-man into Applications. The app and DMG are Developer ID signed and notarized. Requires an Apple Silicon Mac with macOS 13 or later.

**Terminal CLI:** The `.tar.gz` archives contain the CLI, not the menu-bar app. Choose Apple Silicon Mac (`aarch64-apple-darwin`), Intel Mac (`x86_64-apple-darwin`), or Linux x86_64 (`x86_64-unknown-linux-gnu`).

## Homebrew

Install the menu-bar app and CLI together:

```sh
brew trust --formula bootstrap314/tap/ac-man
brew install --cask bootstrap314/tap/ac-man
```

On older Homebrew versions without `brew trust`, skip the first command.

Existing Homebrew users can run `brew update` followed by `brew upgrade --formula bootstrap314/tap/ac-man` and `brew upgrade --cask bootstrap314/tap/ac-man`.

### Security and container distribution

- Weekly security checks run independently on Sundays at midnight GMT, fetching current RustSec and Trivy definitions and uploading Trivy SARIF reports.
- Releases publish a multi-architecture Linux CLI container (amd64/arm64) to GitHub Container Registry after scanning both images. See [container usage and login requirements](https://github.com/bootstrap314/ac-man/blob/main/docs/container.md).
