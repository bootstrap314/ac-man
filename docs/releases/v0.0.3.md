# ac-man v0.0.3

A clearer, more comfortable menu-bar interface for controlling your air conditioners.

## What’s new

- Larger, precisely centered temperature buttons: blue minus for cooler and red plus for warmer.
- Larger operating-mode controls and a more readable device name and current room temperature.
- Dedicated Automatic fan and Boost switches; the fan-speed slider is disabled while either is active.
- Cleaner spacing between the power button, target temperature, and vent settings.
- Updated light and dark product images in the README.
- Documented Homebrew installation for both the menu-bar app and CLI.

## Downloads

**Menu-bar app:** Download `ac-man-app-v0.0.3-macos-apple-silicon.dmg`, open it, and drag ac-man into Applications. The app and DMG are Developer ID signed and notarized. Requires an Apple Silicon Mac with macOS 13 or later.

**Terminal CLI:** The `.tar.gz` archives contain the CLI, not the menu-bar app. Choose Apple Silicon Mac (`aarch64-apple-darwin`), Intel Mac (`x86_64-apple-darwin`), or Linux x86_64 (`x86_64-unknown-linux-gnu`).

## Homebrew

Install the menu-bar app and CLI together:

```sh
brew trust --formula bootstrap314/tap/ac-man
brew install --cask bootstrap314/tap/ac-man
```

On older Homebrew versions without `brew trust`, skip the first command.

Existing Homebrew users can run `brew update` followed by `brew upgrade --formula bootstrap314/tap/ac-man` and `brew upgrade --cask bootstrap314/tap/ac-man`.
