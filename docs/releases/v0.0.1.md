The first public release of **ac-man**, an unofficial Midea SmartHome / MSmartHome cloud controller for macOS and the command line.

## Downloads

### Mac menu-bar app — clickable controls

**[Download the menu-bar app for Apple Silicon Macs (ZIP)](https://github.com/bootstrap314/ac-man/releases/download/v0.0.1/ac-man-macos-v0.0.1-aarch64-apple-darwin.zip)**

Choose this download for an icon in your Mac's menu bar with clickable AC controls. Requires an Apple Silicon Mac and macOS 13 or later. Unzip it, move `ac-man.app` to Applications, and sign in. The app is Developer ID signed, notarized, and stapled. An Intel Mac menu-bar app is not included in this release.

## Features

- **Native macOS menu-bar controls:** choose an AC from the menu and adjust power, target temperature, operating mode, swing, percentage-based fan speed, Auto fan, and Boost where supported.
- **Cloud access:** control online ACs over an internet connection without joining their Wi-Fi network.
- **Automatic device discovery:** load the ACs available to your SmartHome account, assign stable integer IDs, and set local room labels shared by the app and CLI.
- **Responsive controls:** an asynchronous Rust core, connected to Swift through BoltFFI, keeps network operations off the UI thread. Fan sliders preview while dragging and apply on release; commands read back device status.
- **Device-first CLI:** use commands such as `ac-man 1 status`, `ac-man "Office" fan 37`, and `ac-man 1 boost on`. JSON output and combined setting changes support scripting.
- **Secure sign-in:** hidden password prompts, optional password input through stdin, and saved credentials in macOS Keychain or Linux Secret Service. No password command-line argument or bundled household configuration.
- **Open-source build tooling:** Apache 2.0 license, Makefile, Docker CLI builds, PR tests, Cargo Audit, Trivy scans, and manual signed/notarized macOS releases.

This early release is an unofficial client. Available settings depend on the AC model, and changes to Midea's cloud service may affect compatibility.
